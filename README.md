## Overview

Fresh Market Hab is an academic retail scenario focused on a common reporting challenge: sales, inventory, CRM, HR and other information sit in separate systems, making consistent analysis difficult. This project combines **working Power BI and Qlik Sense dashboard prototypes** with an evaluation of possible enterprise BI solutions.

## My contribution

- Developed two Power BI dashboard pages and a comparable Qlik Sense executive overview.
- Built KPI reporting for sales revenue, gross profit, units sold, margin and operational measures using an academic dataset.
- Compared dashboard platforms using weighted requirements for usability, interoperability, security, scalability and cost.
- Proposed a phased architecture: **Fabric Data Factory → Snowflake → semantic modelling → Power BI**. This was a recommendation, **not** a deployed pipeline.
- Coordinated task allocation and collaborated across project research and delivery.

## Recommendation

In the scenario's weighted comparison, Power BI scored **4.75/5** (Tableau 4.45; Qlik Sense 4.25; Looker 4.05). It was recommended for the case organisation based on self-service reporting, modelling and fit with the proposed Microsoft-centric integration environment. These scores are case-specific and not an industry-wide ranking.
